# Proteostasis Activity Score (PAS) for the α-Syn proteostasis network in PD

This repository provides code to calculate the α-Syn proteostasis activity score (PAS) and to run example simulations as described in our study: “The α-Synuclein Proteostasis Network and its Translational Applications in Parkinson’s disease” (doi: https://doi.org/10.1101/2025.03.17.643594).
